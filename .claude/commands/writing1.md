# Writing Task 1 drill (Academic)

## Step 1 — Rotate the visual type

Read `progress/band-tracker.md` and `progress/error-log.md`. Check which Task 1
visual types I have already done, and pick one I have **not** practised recently:

- Line graph (change over time)
- Bar chart (comparison across categories)
- Pie charts (proportions, usually two to compare)
- Table (often no time dimension)
- Process diagram (stages, linear or cyclical)
- Map (change over time, or two site options)
- Mixed (two visuals together — common and awkward)

Say in one line which you chose and why.

## Step 2 — Set the task

Present the data **in text form** — a clear, precise description of the visual I
can work from. Give exact figures, units, time periods and category labels, laid
out as a table or structured list. Make the data realistic and internally
consistent: totals must add up, trends must be describable, and there should be
at least one groupable pattern and one outlier worth an overview.

State clearly:
- **20 minutes**, starting now
- **Minimum 150 words**
- Full sentences, no bullets
- Do not explain causes or give opinions

Then **stop and wait**. No hints, no structure, no model in advance.

## Step 3 — Grade it

Count my words first and report the number, **after subtracting anything I copied
from the prompt** — copied rubric is discounted before the count is taken, and
it is the commonest silent way to fall under 150.

If under 150, do **not** apply a flat penalty; IELTS publishes none. Mark it
where examiners do: name the criteria the shortfall hit — Task Achievement above
all, plus Lexical Resource and Grammar for reduced evidence of range.

### Task 1 specific checks — do all four explicitly

1. **Overview — is it there, and is it real?** State plainly whether I wrote one.
   If missing, say directly that Task Achievement is capped below 7 for that
   reason alone. If present, judge whether it actually summarises the main
   patterns or just restates one number.
2. **Grouping vs listing.** Did I group data by shared pattern, or walk along the
   axis reciting values? Quote the evidence.
3. **Accuracy of figures.** Check every number, unit, date and label against the
   data I was given. Misquoted data is a Task Achievement error — list each one.
4. **No opinions, no causes.** Flag any sentence where I explained *why*
   something happened or judged it. That is outside the task.

Also check: tense correct for the time frame; prompt paraphrased not copied;
comparison language present.

## Step 4 — Fix 3–5 of my exact sentences

Quote verbatim, correct, explain the rule. Prioritise data-description language
(wrong preposition with figures, *increase of* vs *increase in*, singular/plural
with percentages) and my logged L1 interference patterns.

## Step 5 — Name my biggest band-limiter

One thing, stated concretely.

## Step 6 — Band 8 model — AFTER grading only

Now, and **only** now, show a full band-8 model answer for the same data.

Then give a short comparison table: my version vs the model, on overview,
grouping, figure integration, and range of structures. Three or four rows. The
point is for me to see the gap, not to admire the model.

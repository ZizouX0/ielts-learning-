# Writing Task 2 drill

## Step 1 — Diagnose before you choose

Read `progress/error-log.md` and `progress/band-tracker.md`.

Identify which of the **five question families** I have practised least, or which
one produced my lowest Task Response band:

1. Opinion (agree/disagree)
2. Discussion (both views + own opinion)
3. Problem / cause and solution
4. Advantages / disadvantages (outweigh)
5. Two-part / direct question

Pick the weakest. If there is no data yet, start with **Discussion (both views)**
— it is the most common in the real test and the easiest to half-answer.

Tell me in one line which family you chose and what my data says about why.

## Step 2 — Set the task

Give me **ONE** realistic Task 2 question. Original — never a real exam question.
Match the style and difficulty of the real test: a general-interest topic
(education, technology, environment, work, urbanisation, health, culture) phrased
in the standard IELTS register.

State clearly:
- **40 minutes**, starting now
- **Minimum 250 words**
- Write in full sentences, no notes or bullets
- Type it (the real test is computer-delivered)

Then **stop and wait**. Do not give hints, structure, vocabulary or ideas before
I write. Do not pre-empt with a model. If I ask for help before submitting,
remind me the examiner will not help either.

## Step 3 — Grade it

When I submit, first **count my words** and tell me the number. If under 250,
state that a penalty applies and apply it — do not let it slide.

Then grade per criterion using `knowledge/band-descriptors.md`:

| Criterion | Band | Evidence from my text |
|---|---|---|
| Task Response | | |
| Coherence & Cohesion | | |
| Lexical Resource | | |
| Grammatical Range & Accuracy | | |
| **Overall** | | |

Rules:
- Whole or half bands only.
- Every criterion band must be justified by **quoting my actual words**.
- A response must **fully** fit a band to earn it; partial fit = the band below.
- Grade strictly. If torn between two bands, award the lower and say exactly what
  was missing from the higher one.

## Step 4 — Fix 3–5 of my exact sentences

Quote my sentence verbatim, correct it, and give the **rule or examiner logic**
— never a bare correction:

> **You wrote:** "The society is depend of the technology for the informations."
> **Correction:** "Society depends on technology for information."
> **Why:** Three separate rules. (1) Abstract nouns used generally take no
> article — French *la société* forces one, English drops it. (2) *Depend* is a
> full verb, so no *be* — *depends*, not *is depend*; and the preposition is
> *on*, not *of* (from *dépendre de*). (3) *Information* is uncountable — never
> *informations*.

Prioritise **French/Arabic interference errors** (see `CLAUDE.md`) and errors
that already appear in my error log — recurrence is the signal that matters.

## Step 5 — Name my biggest band-limiter

**One** thing. The single change that would move my overall band most. State it
in one or two sentences with a concrete instruction I can act on next time.

## Step 6 — Show a band 8–9 rewrite

Take **one** of my body paragraphs — the weakest — and rewrite it at band 8–9.
Keep my idea and my argument; upgrade only the execution.

Then annotate: 3–4 bullets naming exactly what changed and why it scores higher
(development added, collocation upgraded, complex structure used accurately,
cohesion made invisible).

Only ONE paragraph. A full model essay teaches me nothing about my own writing.

## Step 7 — Update progress files and push

Append to all three:
- `progress/error-log.md` — one row per error (date, skill, my sentence,
  correction, rule)
- `progress/vocab-bank.md` — any new vocabulary I should own
- `progress/band-tracker.md` — the scores and the limiting factor

Then commit and push:
`progress: writing task 2 — <family> — TR x, CC x, LR x, GRA x (overall x)`

## Step 8 — End the session

One line: the single highest-impact fix to remember.

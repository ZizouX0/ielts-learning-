## 1. Paraphrasing the prompt

One sentence. Change the **verb**, the **noun for the visual**, and the **noun for
the data**. Keep every fact.

### The verb swap

| Prompt says | You write |
|---|---|
| shows | illustrates · depicts · presents · sets out · gives · provides |
| gives information about | compares · charts · tracks · traces · documents |
| shows changes | traces the changes in · charts the development of |
| compares | draws a comparison between · sets [A] against [B] |
| shows how X is made | outlines the stages by which [X] is produced |
| shows a place at two dates | records how [X] changed between [1985] and [2010] |

### The visual-noun swap

the graph → **the line graph · the chart · the figure**
the bar chart → **the bar chart · the graph · the chart**
the pie chart → **the pie chart · the two pie charts · the charts**
the table → **the table · the figures · the data**
the diagram → **the diagram · the illustration · the flow chart** (process only)
the map → **the two maps · the plans · the two plans of [Ashcombe]**

⚠ Never write *the given graph* / *the above chart* — memorised-phrase flag.

### The data-noun swap

| Prompt word | Replacements |
|---|---|
| information | data · figures · statistics |
| numbers | figures · totals · levels |
| percentages | proportions · shares · percentage figures |
| spending | expenditure · outlay · the amount spent on |
| people who | the proportion of people who · [X] users · those who |
| money | expenditure · income · revenue · cost |
| how many | the number of · levels of · the volume of |

### 10 ready patterns

1. *The line graph illustrates changes in [X] in [three countries] between [1990] and [2010].*
2. *The bar chart compares [X] across [five categories] in [2022].*
3. *The two pie charts show how [X] was divided in [2010] and in [2025].*
4. *The table sets out figures for [X] in [three countries] over a [twenty-year] period.*
5. *The diagram outlines the process by which [glass bottles] are [recycled].*
6. *The two maps show how [Ashcombe] changed between [1985] and the present day.*
7. *The graph traces the development of [X] over a period of [two decades].*
8. *The chart provides a breakdown of [household waste] by [source].*
9. *The diagram depicts two alternative designs of [a hand-operated well pump].*
10. *The figures compare [X] and [Y] in terms of [Z].*

⚠ *The chart is about…* — too informal. Use a verb from the table.

## 2. Signalling the overview

Two sentences. **No figures.** Begin with one of these.

- *Overall, …* ← the safe default, use it
- *Overall, it is clear that …*
- *It is immediately apparent that …*
- *The most striking feature is that …*
- *The most noticeable trend is that …*
- *The dominant pattern is that …*
- *Broadly, the data fall into two groups: …*
- *In general terms, …*
- *What stands out is that …*
- *Taken as a whole, the figures show that …*

**Second overview sentence — the add-on:**
- *The second point of note is that …*
- *A further point of interest is that …*
- *[X], by contrast, …*
- *The only category to buck this pattern was [X].*

⚠ *In conclusion* / *To sum up* — never in Task 1. There is no conclusion.
⚠ *We can see that* / *I can observe that* — wrong register. Delete.

## 3. Going up

**Verbs (intransitive — nothing after them but an adverb or a preposition)**

| Weak → strong |
|---|
| edge up · inch up · creep up |
| rise · increase · grow · go up |
| climb · advance · escalate |
| surge · jump · leap · shoot up |
| rocket · soar · skyrocket |

**Nouns**

a rise · an increase · growth · an upward trend · an upturn · a climb ·
a surge · a jump · a leap · an escalation · a boom

**With adverbs (verb + adverb)**

rose slightly · rose gradually · rose steadily · climbed steadily ·
increased significantly · grew substantially · rose sharply · surged dramatically

**Other useful shapes**

- *[X] showed an upward trend.*
- *[X] was on the rise throughout the period.*
- *[X] followed an upward path.*
- *[X] more than doubled.*
- *There was a marked upturn in [X].*
- *[X] saw considerable growth.*
- *[X] recorded its strongest growth between [1995] and [2000].*

⚠ *was increased* — wrong. *rise, fall, increase, decrease, grow, decline* are
intransitive. ✗ *the number was increased* → ✓ *the number increased*.
⚠ *raise* is a different verb and needs an object: ✗ *sales raised* → ✓ *sales rose*.
⚠ *augmented* (French) → ✓ *rose · increased*.
⚠ *skyrocketed / rocketed* — only for a genuinely explosive rise. Wrong size = TA error.

## 4. Going down

**Verbs**

| Weak → strong |
|---|
| dip · edge down · slip · ease |
| fall · decrease · decline · drop · go down · reduce (no object → use *fall*) |
| sink · slide · shrink · contract |
| plunge · slump · tumble · dive |
| plummet · collapse · crash |

**Nouns**

a fall · a decrease · a decline · a drop · a dip · a downturn ·
a reduction · a slump · a plunge · a collapse · a downward trend

**With adverbs**

fell slightly · dipped marginally · declined gradually · fell steadily ·
dropped noticeably · fell sharply · plunged dramatically

**Other useful shapes**

- *[X] showed a downward trend.*
- *[X] was in decline over the period.*
- *[X] halved / fell by half.*
- *[X] fell back to its [1990] level.*
- *There was a steady decline in [X].*
- *[X] saw the steepest fall of any category.*
- *[X] lost ground throughout the period.*

⚠ *diminution* (French) → ✓ *decline · drop · fall*.
⚠ *decreased strongly* — wrong collocation → ✓ *decreased sharply · fell steeply*.
⚠ *plummeted* for a 3% fall is an accuracy error, not just a lexical one.
⚠ *reduce* needs an object (*the plant reduces waste*). For a bare fall use *fall*.

## 5. No change / stability

**Verbs**

remain stable · remain steady · remain constant · remain unchanged ·
stay the same · hold steady · stand at · level off · plateau · flatten out ·
stabilise · show little change · change little · vary little

**Nouns / adjectives**

stability · no significant change · a period of stability ·
stable · steady · constant · unchanged · flat · static

**Ready sentences**

- *[X] remained stable at around [5 million] throughout the period.*
- *[X] showed almost no change over the two decades.*
- *[X] held steady at [40 per cent].*
- *[X] levelled off after [2005] and changed little thereafter.*
- *[X] stood at [200] in both years.*
- *There was no appreciable change in [X].*
- *[X] was the one category to remain untouched.*
- *[X] fluctuated slightly but ended the period roughly where it began.*

⚠ *level off* and *plateau* mean **stopped rising** — not *fell*. Using them for a
fall is a factual error.
⚠ preposition: *remained stable **at** 5 million* — not *stable to*.

## 6. Fluctuation and irregular movement

**Verbs**

fluctuate · vary · oscillate · swing · waver · move erratically ·
rise and fall · go up and down

**Nouns**

fluctuation · variation · volatility · an erratic pattern · ups and downs

**Ready sentences**

- *[X] fluctuated between [40] and [60] over the period.*
- *[X] fluctuated wildly / slightly / considerably before settling at [X].*
- *[X] followed an erratic course, with no clear overall direction.*
- *After a period of volatility, [X] settled at around [50].*
- *[X] rose and fell repeatedly, ending the period close to its starting figure.*
- *[X] showed considerable year-on-year variation.*

**Adverbs that fit**: wildly · erratically · considerably · slightly · sharply

⚠ *fluctuate* is intransitive: ✗ *was fluctuated* → ✓ *fluctuated*.
⚠ preposition: *fluctuated **between** X **and** Y*, *fluctuated **around** 50*.

## 7. Peaks, lows and turning points

**Highs**

- *[X] peaked at [11 million] in [2004].*
- *[X] reached a peak of [11 million].*
- *[X] reached a high of [11 million].*
- *[X] hit its highest point in [2004].*
- *[X] reached its maximum in [2004], at [11 million].*
- *[X] climbed to an all-time high of [11 million].*
- *The peak came in [2004].*

**Lows**

- *[X] bottomed out at [2 million] in [1998].*
- *[X] reached a low of [2 million].*
- *[X] fell to its lowest point in [1998].*
- *[X] hit a trough in [1998].*
- *[X] reached a record low.*

**Turning points and reversals**

- *[X] rose until [2000], after which it began to fall.*
- *[X] reversed direction in [2000].*
- *The trend was reversed after [2000].*
- *[X] recovered / rebounded / picked up after [2000].*
- *[X] fell back sharply from its peak.*
- *[X] resumed its upward path in [2005].*
- *[X] overtook [Y] around the midpoint of the period.*
- *The two lines crossed in [2005].*

**Flattening**

- *[X] levelled off at around [50].*
- *[X] plateaued for the remainder of the period.*
- *Growth tailed off after [2010].*

⚠ **the preposition split**: *peaked **at** 11 million* (verb) but *a peak **of**
11 million* (noun). ✗ *peaked to* · ✗ *a peak at*.
⚠ *bottomed out* means it stopped falling — it does not mean it rose.

## 8. Degree and speed of change

Two separate scales. You need the **adverb** (goes with a verb) and the
**adjective** (goes with a noun) of each.

### DEGREE — how big

| Size | Adverb (verb + adv) | Adjective (a … rise) |
|---|---|---|
| tiny | marginally · minimally · negligibly | marginal · minimal · negligible |
| small | slightly · a little · modestly | slight · small · modest |
| moderate | moderately · noticeably · appreciably | moderate · noticeable · appreciable |
| large | significantly · substantially · considerably · markedly | significant · substantial · considerable · marked |
| very large | dramatically · sharply · steeply · drastically · enormously | dramatic · sharp · steep · drastic · enormous |

### SPEED — how fast

| Speed | Adverb | Adjective |
|---|---|---|
| slow, even | gradually · steadily · progressively · slowly | gradual · steady · progressive · slow |
| brisk | quickly · rapidly · swiftly | quick · rapid · swift |
| instant | suddenly · abruptly · overnight | sudden · abrupt |

**Combining both:** *rose steadily but substantially* · *a sudden, marked increase*
· *fell gradually at first and then sharply*.

⚠ *significative* is not an English word → ✓ *significant*.
⚠ *an important increase* (French *importante*) → ✓ *a substantial increase*.
⚠ *strongly* does not collocate with rise/fall → ✓ *sharply · steeply*.
⚠ *hardly* ≠ *slightly*. *Hardly rose* = almost no rise at all.

## 9. THE TWO GRAMMAR SHAPES — alternate these

Same fact, two structures. Use both in every report. This is the cheapest
Grammatical Range point in Task 1.

| Shape 1 — **verb + adverb** | Shape 2 — **there was a + adjective + noun** |
|---|---|
| *Car use rose sharply.* | *There was a sharp rise in car use.* |
| *Sales fell steadily between 1990 and 2000.* | *There was a steady fall in sales between 1990 and 2000.* |
| *Cycling declined marginally.* | *There was a marginal decline in cycling.* |
| *Expenditure grew dramatically after 2005.* | *There was a dramatic growth in expenditure after 2005.* |
| *Attendance fluctuated considerably.* | *There was considerable fluctuation in attendance.* |

**Two further shapes worth owning:**

- **Change as subject:** *The steepest decline occurred between [1995] and [2000].*
  · *The sharpest rise came in [2004].* · *The biggest change was in [X].*
- **[X] saw / experienced / underwent:** *[Germany] saw a sharp rise in [X].* ·
  *[The sector] experienced a marked decline.*
- **Participle clause:** *Sales climbed steadily, rising to a peak of [40%] before
  falling back.*

⚠ preposition after the noun: *a rise **in** sales* — not *a rise of sales*
(*a rise **of** 7 million* means the size of the rise).

## 10. COMPARISON — the biggest section

The rubric demands it: *make comparisons where relevant*. On any visual with no
time axis, this section replaces §3–§8 entirely.

### 10.1 Comparatives

**Form:** one syllable → **-er** (higher, lower, larger, smaller, faster, greater).
Two syllables ending *-y* → **-ier** (heavier, steadier). Otherwise → **more** +
adjective (more expensive, more common, more significant).

**The workhorses**

higher than · lower than · greater than · larger than · smaller than ·
more common than · less common than · more popular than · faster than ·
steeper than · more pronounced than · more marked than

**Intensified — put an adverb in front of the comparative**

| Big gap | Small gap |
|---|---|
| far higher than | slightly higher than |
| significantly higher than | marginally higher than |
| considerably higher than | a little higher than |
| substantially higher than | somewhat higher than |
| markedly higher than | fractionally higher than |
| well above / well below | just above / just below |
| nowhere near as high as | almost as high as |

**Ready sentences**

- *[A] was significantly higher than [B] in every year.*
- *Spending on [X] was far greater than on [Y].*
- *[A] recorded a considerably steeper rise than [B].*
- *The figure for [A] was only marginally lower than that for [B].*
- *[A] was well above the average for the group.*
- *The gap between [A] and [B] widened / narrowed over the period.*

**The errors — one line each**

✗ *more higher* → ✓ **much higher · far higher**
✗ *more bigger* → ✓ **far bigger**
✗ *most highest* → ✓ **the highest**
✗ *higher that [B]* (French *que*) → ✓ **higher than [B]**
✗ *more high* → ✓ **higher**
✗ *the most big* → ✓ **the biggest**
✗ *[A] is more high than [B] of 20%* → ✓ **[A] is 20% higher than [B]**
✗ *very higher* → ✓ **much higher**
✗ *[A] is superior to [B]* (French *supérieur à*) → ✓ **[A] is higher than [B]**
✗ *[A] is inferior to [B]* → ✓ **[A] is lower than [B]**

### 10.2 Superlatives

the highest · the lowest · the largest · the smallest · the greatest ·
the most common · the least common · the most popular · the least popular

**Ranking inside a superlative**

- *the second highest · the third largest · the second most common*
- *the next highest · the next largest*
- *by far the largest* · *easily the highest* · *comfortably the lowest*
- *the highest of the five* · *the highest of any country shown*
- *the single largest category*
- *[X] recorded the highest figure, at [210 litres].*
- *[X] was the least popular option, chosen by only [8 per cent].*
- *At the other end of the scale, [X] accounted for just [4 per cent].*

⚠ *the* is compulsory with a superlative: ✗ *[A] was highest* → ✓ *[A] was **the** highest*.
(*[A] was highest in 2010* is acceptable only where you mean "at its own highest".)
⚠ ✗ *the more high* · ✗ *the most highest*.
⚠ ✗ *the second the highest* → ✓ *the second highest*.

### 10.3 Multiples and ratios

| Meaning | Say it like this |
|---|---|
| ×2 | *twice as many as* · *twice as much as* · *double the figure for [B]* · *[A] is double [B]* |
| ×3 | *three times as many as* · *three times higher than* · *treble the number of* |
| ×10 | *ten times as many as* · *a tenfold increase* |
| ×½ | *half as many as* · *half as much as* · *half the figure for [B]* |
| ×⅓ | *a third as many as* · *a third of the figure for [B]* |
| growth ×2 | *doubled* · *more than doubled* · *nearly doubled* |
| growth ×3 | *trebled* · *tripled* |
| fall ×½ | *halved* · *fell by half* |
| open-ended | *more than twice as many as* · *over three times higher than* · *upwards of four times* |

**Ready sentences**

- *[A] used more than twice as much water per head as [C].*
- *The figure for [A] was three times that for [B].*
- *[A] was double the figure recorded in [B].*
- *There was a fivefold difference between the highest and lowest figures.*
- *[X] rose tenfold over the period.*
- *For every [one] person who [X], [three] chose [Y].*
- *The ratio of [A] to [B] was roughly two to one.*

⚠ ✗ *twice more than* (French *deux fois plus que*) → ✓ **twice as many as**.
⚠ ✗ *three times more high* → ✓ **three times higher**.
⚠ **countable vs uncountable**: *as **many** as* + plural count (*as many cars as*);
*as **much** as* + uncountable (*as much water as*).
⚠ *twice as many as* takes **as**, not *than*: ✗ *twice as many than*.
⚠ Check the arithmetic before you write the multiple. 185 ÷ 90 = 2.06 is *just over
twice*, not *well over twice*.

### 10.4 Equality and similarity

as high as · as many as · as much as · the same as · identical to ·
comparable to · comparable with · on a par with · roughly equal to ·
broadly similar to · at a similar level to · close to

**Adverbs and linkers**

similarly · likewise · equally · in the same way · correspondingly ·
in both cases · in each of the [three] countries

**Both / neither**

- *Both [A] and [B] rose over the period.*
- *[A] and [B] alike showed a steady increase.*
- *Neither [A] nor [B] changed appreciably.*
- *The same was true of [B].*
- *[B] followed a similar pattern.*
- *[B] mirrored this trend.*
- *[A] and [B] were almost identical, at [40] and [41] respectively.*

⚠ *as high as [B]* takes **as … as**: ✗ *as high than* → ✓ *as high as*.
⚠ *the same **as***, not *the same **that***, not *the same **like***.
⚠ *similar **to***, not *similar **with*** (but *comparable **to/with*** are both fine).
⚠ *Both* takes a plural verb: ✗ *both was* → ✓ *both were*.

### 10.5 Difference and contrast

**Subordinators — inside one sentence**

whereas · while · although · even though · despite the fact that

- *[A] rose steadily, whereas [B] moved in the opposite direction.*
- *While [A] climbed, [B] held steady.*
- *Although [B] declined, it remained the second most common mode.*

**Sentence linkers — between sentences**

By contrast, · In contrast, · Conversely, · On the other hand, ·
[B], however, · [B], by comparison, ·

**Prepositional phrases**

compared with [B] · in comparison with [B] · relative to [B] ·
as against [B] · unlike [B] · in contrast to [B] · as opposed to [B]

**Contrast verbs — the band-7 ones**

- *[A] outstripped [B] by a wide margin.*
- *[A] outnumbered [B] three to one.*
- *[A] outperformed [B] in every category.*
- *[B] lagged behind [A] throughout.*
- *[B] trailed the other categories.*
- *[B] fell short of [A] by [10] percentage points.*
- *[A] overtook [B] in [2005].*
- *[A] far exceeded [B].*
- *[A] dwarfed the remaining categories.*
- *The gap between [A] and [B] widened to [20] points.*
- *[A] and [B] diverged sharply after [2000].*

**Naming the difference**

- *The chief difference lies in [X].*
- *The most obvious contrast is between [A] and [B].*
- *[A] differs from [B] in that it [X].*
- *[A] stands apart from the rest of the group.*
- *The sole exception was [X].*

⚠ *on the **other** hand*, not *in the other hand*.
⚠ *whereas* / *while* join two clauses inside one sentence; *however* / *by contrast*
start a new sentence. ✗ *[A] rose, however [B] fell.* → ✓ *[A] rose; however, [B] fell.*
⚠ *compared **with/to***, not *comparing to*.
⚠ *different **from***, not *different of*.
⚠ *contrary to* is not a synonym of *by contrast*. Use *by contrast* for data.

### 10.6 Ranking

- *[A] ranked first, followed by [B] and [C].*
- *[A] came first / came second / came bottom.*
- *[A] topped the list, at [210].*
- *[A] headed the table.*
- *[A] took first place, narrowly ahead of [B].*
- *[A] occupied second place.*
- *[B] was the second most popular choice.*
- *[C] came last, with just [40].*
- *[C] was the least popular category by some margin.*
- *At the other end of the scale, [C] …*
- *The remaining [three] categories all fell below [50].*
- *In descending order, the leading categories were [A], [B] and [C].*
- *[A] led on every measure except [X].*

⚠ *ranked first*, not *ranked at the first place*.
⚠ *the first mode* means the earliest, not the biggest → ✓ *the leading mode*.

## 11. Proportions, fractions and percentages

**Fractions**

a quarter · a third · two thirds · three quarters · four fifths ·
a half · three fifths · a tenth · a fifth

**Quantifiers of a whole**

the vast majority · a large majority · a small majority · just over half ·
a significant minority · a small minority · a tiny fraction · a negligible share ·
the bulk of · the remainder · the rest · the balance

**"One in …"**

one in five · one in ten · two in every three · nine out of ten ·
fewer than one in twenty

**Verbs of composition**

- *[X] accounted for [34] per cent of the total.*
- *[X] made up [a third] of all [waste].*
- *[X] constituted [the largest] share.*
- *[X] represented [a quarter] of the total.*
- *[X] comprised [three] main categories.* ⚠ never *comprised of*
- *[X] consisted of [three] elements.*
- *[X] contributed [15] per cent.*
- *[X] took the largest share, at [34] per cent.*
- *[X] was responsible for [a fifth] of the total.*
- *The total was made up of [A], [B] and [C].*
- *[A] and [B] together accounted for well over half.*

**Percentage points vs per cent** ⚠
20% → 30% is a rise of **10 percentage points**, or of **50 per cent**.
If unsure, write *rose from 20% to 30%* and sidestep it entirely.

⚠ *accounted **for*** — not *accounted 40%*.
⚠ *a proportion* is a part of a whole: ✗ *the proportion of 5 million* → ✓ *the figure of 5 million*.
⚠ *the number of cars **was*** (singular) but *a number of cars **were*** (plural).
⚠ *the majority of respondents **were*** (plural), *the proportion of women **was*** (singular).
⚠ ✗ *20 per cents* · ✗ *five millions* → ✓ *20 per cent* · *five million*.
⚠ *percentage* needs *the* or a modifier: ✗ *percentage of women rose* →
✓ *the percentage of women rose*.
⚠ On a **percentage** pie chart you cannot say the *number* rose — only the *share* did.

## 12. Approximation

**BELOW the figure** — *nearly · almost · just under · a little under · not quite ·
close to · approaching · fewer than · under*

**ABOVE the figure** — *just over · a little over · slightly more than · well over ·
upwards of · in excess of · more than · over*

**EITHER SIDE** — *approximately · roughly · around · about · some · in the region
of · of the order of · or so · give or take*

**Ready sentences**

- *just over [40,000]* · *just under [half]*
- *in the region of [200]*
- *some [15] per cent*
- *upwards of [half]*
- *approximately [one third]*
- *roughly [double] the figure for [B]*
- *well over [half] of all respondents*
- *a figure approaching [90] per cent*
- *between [45] and [50] percentage points*

⚠ **This is the trap: *nearly, almost, just under* mean BELOW the number. *Just over,
well over, upwards of* mean ABOVE it.** Putting a figure on the wrong side is a
factual error, not a style choice.
⚠ *well over* means *clearly* above. For 2.06× do not write *well over twice*.
⚠ Rotate them. *Approximately* six times is restricted range.
⚠ When one approximation has to cover several figures, check it against the **worst**
one — otherwise write a range: *between [45] and [50]*.

## 13. Time and periods

**Spans**

over the period · over the two decades · over the twenty years in question ·
throughout the period · across the whole period · during the [1990s] ·
between [1990] and [2010] · from [1990] to [2010] · in the years from
[1990] to [2010] · for the first [ten] years · over the remainder of the period

**Points**

in [1990] · in [March] · at the start of the period · at the outset ·
by [2010] · by the end of the period · at the midpoint · midway through the period ·
in the final year · as of [2010]

**Sequence within a trend**

initially · at first · in the early years · in the first decade ·
thereafter · from that point on · in the years that followed ·
subsequently · over the following decade · in the closing years ·
by the end · finally

**Rate expressions**

annually · per year · year on year · per head · per person · per capita ·
per household · on a daily basis · a decade-long increase

**Ready sentences**

- *Over the period as a whole, [X] rose by [7 million].*
- *Between [1990] and [2010], [X] more than doubled.*
- *During the first decade, [X] changed little; thereafter it rose sharply.*
- *By [2010], [X] had overtaken [Y].*
- *In the years that followed, the trend was reversed.*
- *[X] rose throughout, with the exception of a brief dip in [1998].*

⚠ ✗ *between 1990 to 2010* → ✓ *between 1990 **and** 2010* / *from 1990 **to** 2010*.
⚠ ✗ *during 20 years* → ✓ *for 20 years · over a 20-year period*.
⚠ ✗ *at 1990* → ✓ *in 1990*.
⚠ ✗ *since 1990* unless the trend runs to now. *Since* + start point, *for* + length.
⚠ ✗ *a twenty-years period* → ✓ *a twenty-year period* (no *-s* on the modifier).
⚠ ✗ *in the 1990's* → ✓ *in the 1990s*.

## 14. Tense — decide in three seconds

| What you see | Tense | Example |
|---|---|---|
| Dated past range (*1990–2010*) | past simple | *Car use **rose** from 4 to 11 million.* |
| Range running to *"the present day"* | present perfect | *Car use **has risen** steadily.* |
| Undated / typical (*"a typical day"*) | present simple | *Most journeys **are** made by car.* |
| Categorical bars, undated table | present simple | *Country A **uses** more water than Country C.* |
| Projected / future part of the graph | *is expected to · is projected to · will* | *Demand **is projected to** reach 20 million by 2030.* |
| Man-made process | present simple **passive** | *The glass **is crushed** into cullet.* |
| Natural cycle | present simple, mostly **active** | *The larva **hatches** after ten days.* |
| Static diagram, object or device | present simple, mostly **active** | *The handle **pivots** on a steel pin.* |
| Static diagram of a historical artefact | past simple | *The chamber **was lined** with brick.* |
| Maps: dated past → dated past | past simple passive | *A car park **was built** on the site.* |
| Maps: past → *"today" / "now"* | present perfect passive | *The woodland **has been cleared**.* |
| Maps: present → *proposed / planned* | modal passive | *A marina **will be constructed**.* |

**Switch tense at the projection boundary** — past/present for the data, future
forms only for the dotted part.

⚠ The commonest leak is a relative clause: ✗ *the number of people who **use** the
bus fell* → ✓ *the number of people who **used** the bus fell*. Keep the tense
consistent inside the sentence.
⚠ *Today* / *now* / *at present* on a map = present perfect. A **date** (*2025*) =
past simple. Never infer "today" from a recent date.

## 15. PROCESS DIAGRAMS

### Sequencers — rotate, do not head every sentence with one

**Start:** initially · at the outset · in the first stage · to begin with ·
the process begins with · the first step involves

**Middle:** subsequently · following this · next · after this · at this stage ·
at this point · meanwhile · simultaneously · in the following stage ·
once [X] has been completed · after [X] has been [collected] · having been [washed]

**End:** in the final stage · finally · lastly · ultimately ·
the process ends with · at which point the [bottles] are ready for despatch

### Passive forms — vary the shape

| Shape | Example |
|---|---|
| plain passive | *The glass **is sorted** by colour.* |
| passive + adverb | *The mixture **is then thoroughly heated**.* |
| passive + purpose infinitive | *The pulp **is pressed to remove** excess water.* |
| present perfect passive | *Once the bricks **have been fired**, they are packed.* |
| passive after *before* + *-ing* | *The ore **is crushed before being melted**.* |
| modal passive | *The residue **may be recycled** into the next batch.* |
| *undergo* (active but formal) | *The material **undergoes** a second filtration.* |

### Purpose and result

in order to · so as to · so that · with the aim of · for the purpose of ·
this ensures that · this allows [X] to [Y] · thereby [producing] ·
resulting in · which results in

### Precise process verbs — the LR lever

extracted · quarried · mined · harvested · collected · sorted · graded ·
washed · rinsed · soaked · crushed · ground · milled · sieved · filtered ·
separated · blended · mixed · heated · smelted · melted · fired · baked ·
dried · cooled · cured · annealed · moulded · cast · pressed · rolled ·
cut · shaped · assembled · sealed · treated · purified · packaged ·
labelled · stored · transported · distributed · despatched

⚠ Never *put in · made · done · get*. Verb precision is the whole LR score here.

### Counting and naming stages

- *The process comprises [seven] distinct stages.*
- *The process consists of [seven] stages, from [collection] to [packaging].*
- *There are [seven] main stages, beginning with [X] and ending with [Y].*
- *The process can be divided into [three] broad phases.*
- *The [first] phase covers [collection and preparation].*

⚠ Counting stages is **not** an overview. Name the **phases**.

### Cyclical processes

- *The cycle begins when [X].*
- *This in turn triggers [Y].*
- *…, at which point the cycle begins again.*
- *…, thereby completing the cycle.*
- *The process is continuous, with no fixed end point.*
- *The [salmon] returns to [the river of its birth], and the cycle repeats.*

⚠ A cycle does not *finish*. If a return arrow is drawn on the diagram, do not
end with *finally*.

### Inputs and outputs

- *The raw material for the process is [used glass].*
- *[Sand] and [soda ash] are added at this stage.*
- *The end product is [a finished bottle].*
- *The by-product, [slag], is removed and discarded.*
- *The waste [water] is fed back into the system.*

## 16. MAPS

### Compass and position

| Inside the area | Beyond the edge |
|---|---|
| in the north · in the northern part | to the north of · north of |
| in the south-east corner | to the south-east of |
| in the centre · at the heart of | on the outskirts of · beyond the town |

**More position language**

adjacent to · next to · alongside · beside · opposite · facing ·
surrounded by · enclosed by · bordered by · flanked by ·
on either side of · on the far side of · across the river from ·
in the top left-hand corner · along the coast · on the coastline ·
runs alongside · runs through · runs parallel to · cuts across ·
adjoins · borders · overlooks · stretches from [X] to [Y] ·
occupies the [eastern] half · lies between [X] and [Y] ·
within walking distance of · at the junction of

⚠ *in the north* = inside the area. *to the north of* = outside it. This is worth a mark.
⚠ No compass rose drawn? **North is the top of the map.**

### Change verbs — four families

**Replace:** was replaced by · gave way to · made way for · was converted into ·
was turned into · was transformed into · now occupies the site of ·
stands where [X] once stood

**Add:** was built · was constructed · was erected · appeared · was introduced ·
was added · sprang up · was developed · was laid out

**Remove:** was demolished · was pulled down · was knocked down · was cleared ·
was removed · disappeared · was lost to [housing] · no longer exists

**Resize / move:** was extended · was enlarged · was expanded · doubled in size ·
was widened · was reduced in size · was scaled back · was relocated to ·
was moved to the [north] of the site

**Continuity:** remained unchanged · was retained · was left intact ·
was untouched · survived the period · is still in place · continues to occupy

### Ready sentences

- *The farmland to the north of the river gave way to a housing estate.*
- *A road bridge was built in place of the ferry crossing.*
- *The school was extended to twice its original size.*
- *The church at the centre of the village remained unchanged.*
- *The most far-reaching change was the loss of [farmland] on the [north] bank.*
- *[Ashcombe] has been transformed from a [farming] settlement into a [residential] one.*
- *The area has become considerably more built-up.*

### Character-shift vocabulary for the overview

rural → residential · agricultural → industrial · industrial → leisure ·
undeveloped → urbanised · became more built-up · underwent extensive development ·
lost its [agricultural] character · was redeveloped for [housing]

**Tense:** second plan dated (*2025*) → past simple passive. Second plan undated
(*today, now*) → present perfect passive. Second plan *proposed* → *will be built*.

## 17. STATIC DIAGRAMS (an object or device — no time, no sequence)

⚠ **No trend verbs at all here.** *Rose, fell, increased, remained stable* are all
factually wrong: the diagram shows a **difference**, not a change.
⚠ **No sequencers either.** *Initially, subsequently, finally* invent an order.

### Parts — what it is made of

consists of · comprises (⚠ never *comprises of*) · is made up of · contains ·
is composed of · incorporates · features · is fitted with · is equipped with ·
is mounted on · is attached to · is connected to · is joined to · houses ·
is encased in · is enclosed within · is lined with · is coated in

### Function — what a part does

serves to [X] · functions as [X] · acts as [X] · is responsible for [X] ·
allows [the water] to [pass] · enables [X] to [Y] · prevents [heat] from [escaping] ·
keeps [X] out · draws [water] up · channels [X] towards [Y] · supports · secures ·
seals · absorbs · traps · filters · regulates · transmits · converts [X] into [Y] ·
rotates · pivots · slides · swings · is designed to [X]

### Position

at the base · at the upper end · at the top · directly beneath · immediately above ·
adjacent to · alongside · at either end · running the length of · on the underside ·
at right angles to · flush with · set into · recessed into · protruding from ·
vertically · horizontally · at the centre · around the perimeter · in the upper section

### Comparison between two objects — the sentences that earn the band

- *Whereas the first design [uses a piston], the second [uses a rope loop].*
- *Unlike the first design, the second [has no moving parts below ground].*
- *In place of [the cylinder], the second design has [a narrow pipe].*
- *The equivalent component in the second design is [the guide block].*
- *A comparable function is performed by [the washers].*
- *Both designs share [a hand-operated drive].*
- *Neither design requires [an external power source].*
- *The chief difference lies in [how the water is lifted].*
- *The second design dispenses with the [sealed cylinder] found in the first.*
- *Where the first uses [X], the second uses [Y].*
- *The two perform the same task by fundamentally different means.*

### Grouping — never object by object

Useful groups: *structure / power source / user interface* · *what it is made of /
how it is held together* · *the part above ground / the part below* · *the parts
that move / the parts that do not* · *input / output*.

⚠ You must **leave labels out**. Selection is the band-7 move here.
⚠ No commentary: you may say design B has fewer moving parts; you may not say it is
therefore more reliable.

## 18. TABLES with no time dimension

Compare **across categories**, not over time. Present simple. No trend verbs.

**Selecting**

- *The most striking figures are for [X] and [Y].*
- *[X] records the highest figure in every column.*
- *[X] is the only category to exceed [90] in all three countries.*
- *The remaining categories cluster between [40] and [60].*
- *Mid-range figures show little variation and are not discussed here.*

**Comparing across a row and down a column**

- *Across all three countries, [nursing] graduates fare best.*
- *In every country, [fine art] comes bottom.*
- *[Canada] leads on all subjects except [nursing].*
- *The spread within [Portugal] is wider than in the other two countries.*
- *The gap between the best and worst categories is between [45] and [50] points.*
- *[X] varies little between countries, whereas [Y] varies considerably.*
- *The pattern is consistent across all three columns.*
- *The one exception to this pattern is [X].*

**Naming the organising insight** (a table overview must say something no cell says)

- *Overall, [the subject studied] matters far more than [the country of study].*
- *Overall, the differences between categories are far larger than the differences
  between countries.*
- *Overall, the figures divide into two clearly separated groups.*

⚠ ✗ *Country A increased to 210* on an undated table → ✓ *Country A stands at 210*.

## 19. Cohesion without repeating nouns

**Reference — point back with a short phrase**

this figure · this trend · this pattern · this shift · this reversal ·
this change · these categories · these three countries · such growth ·
the former · the latter · both · the other two · the remaining two ·
the rest · the others · that of · those of · the same

**Substitution and ellipsis**

- *[A] rose sharply; [B] did so more gradually.* (*did so* = rose)
- *[A] was higher than that of [B].* (*that* = the figure)
- *The figures for [A] exceeded those for [B].* (*those* = the figures)
- *The number of children travelling by car rose, while the number walking fell.*
  (ellipsis — *of children* left out)
- *[A] rose, and so did [B].*
- *[A] fell; [B] did not.*

**Ready cohesion sentences**

- *This shift was the most striking feature of the period.*
- *The former rose steadily; the latter fell by a comparable margin.*
- *The remaining two categories followed the same downward path.*
- *Both moved in the same direction, though at very different speeds.*
- *The same was true of [B].*
- *In doing so, it overtook [B] for the first time.*

⚠ **Every substitute must have exactly one possible antecedent.** If *those* could
point at two things, use ellipsis or repeat the noun.
⚠ *the former / the latter* work only with **exactly two** items, in that order.
⚠ *that of* is singular, *those of* is plural: ✗ *the figures for A exceeded that of B*.

## 20. Words to stop using, and what to use instead

| Band-6 default | Band-7 replacement |
|---|---|
| a lot of · lots of | a substantial proportion of · a large share of |
| big / small (of a figure) | substantial / marginal · considerable / slight |
| went up / went down | rose / fell · climbed / declined |
| got bigger | grew · expanded · widened |
| a big rise | a substantial rise · a marked increase |
| very high | considerably higher · well above the rest |
| people | respondents · consumers · residents · households · participants |
| things | factors · categories · items · components |
| good / bad (of a figure) | favourable / unfavourable · strong / weak |
| the same time | the same period · concurrently |
| in the last | over the final [decade] |
| a small amount | a small quantity · a modest figure |
| more and more | increasingly · a growing number of |
| firstly / secondly / thirdly stacked | *(delete two of the three)* |
| moreover / furthermore at every sentence head | *(replace with reference — see §19)* |
| talk about | show · indicate · record |
| we can see that | the chart shows that *(or delete)* |
| in the other hand | on the other hand |
| in a first time | initially |
| it is to be noted that | notably |
| nowadays | at present · currently |
| percentage of people | the proportion of respondents |

**⚠ The warning that matters more than the table.**
A wrong upgrade scores **lower** than the plain word. *Sales rose sharply* beats
*sales skyrocketed* used for a 5% rise. *Plummeted* for a 3% fall costs you twice —
once on vocabulary, once on accuracy. Band-7 vocabulary is judged on **collocation
and precision**, not rarity. If you are not certain the pairing is normal English,
write the plain word.

**Five that never survive the upgrade — use the plain form:**
✗ *significative* → ✓ significant
✗ *augmented* → ✓ rose · increased
✗ *diminution* → ✓ decline · drop
✗ *the evolution of the trend* → ✓ the change · the trend
✗ *an important increase* → ✓ a substantial increase
